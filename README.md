# 📈 AI Stock Predictor

An AI-powered stock market prediction and backtesting web application built with Python and Flask.

The system combines LSTM-based price prediction, technical indicators, sentiment analysis, fundamental analysis, risk management, and historical backtesting to generate a final market signal.

## 🚀 Features

- 🤖 LSTM-based stock price prediction
- 📊 Technical analysis
- 📈 SMA 20 / 50 / 200
- 📉 RSI indicator
- 📐 ATR-based risk management
- 📊 ADX trend detection
- 📰 News sentiment analysis
- 🏢 Fundamental analysis
- 🟢 BUY / 🔴 SELL / 🟡 WAIT-HOLD signals
- 🛡️ Stop Loss and Target calculation
- 📋 Historical backtesting
- 💰 Profit/Loss calculation
- 📉 Maximum Drawdown
- 📊 Profit Factor
- 📈 Win Rate
- ⚡ Live stock price
- 🌐 Flask web interface
- 📱 Responsive dashboard

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/RoshanKhodape/AI-Stock-Predictor.git
```

Go to the project directory:

```bash
cd AI-Stock-Predictor
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

## 📊 Backtesting

The application includes a historical backtesting engine that evaluates:

- Total Trades
- Winning Trades
- Losing Trades
- Win Rate
- Net Profit/Loss
- Total Return
- Profit Factor
- Maximum Drawdown
- Sharpe Ratio
- Gross Profit
- Gross Loss

The strategy includes ATR-based Stop Loss, risk-based position sizing, break-even logic, trailing stop, target exits, transaction costs, and non-overlapping trades.

## 🛡️ Risk Management

```text
ATR Stop Loss
       ↓
Position Sizing
       ↓
Break-even
       ↓
Trailing Stop
       ↓
Target Exit
```
